CHILL ZONE ZENITH - FIX 5: ADMIN TESTING GIVE COMMAND

This includes everything from Fix 4 plus an easy testing command.

ADMIN TEST COMMAND:
    /zenith give <item>

The <item> part AUTOCOMPLETES every custom Zenith item/block currently registered.

Examples:
    /zenith give ender_essence
    /zenith give shulker_essence
    /zenith give ender_blade
    /zenith give ender_dragon_blade
    /zenith give ravager_horn
    /zenith give warden_heart
    /zenith give zenith_blade
    /zenith give ender_crafting_table

You can therefore test the recipes without farming rare drops first.

Vanilla /give also still works:
    /give @s chillzonezenith:ender_essence
    /give @s chillzonezenith:ender_blade

The /zenith give command is only an ADMIN TESTING shortcut.
Normal players still need to earn/craft the items normally once drops and restricted
branch crafting are wired in.
